# 📚 Reading Log

매일 책을 읽고, 읽은 내용과 생각을 기록합니다.

단순히 책을 많이 읽는 것보다  
**읽기 → 생각하기 → 기록하기**를 꾸준히 이어가는 것을 목표로 합니다.

---

## 📌 Reading Rule

- 매일 19:00 독서
- 기본 목표: 20분
- 너무 피곤한 날은 5분이라도 읽기
- 읽은 후 짧은 독서 기록 남기기
- 책을 완독하면 `완독-기록.md` 작성
- 독서 기록은 Git으로 commit

> 페이지 수나 완독 권수보다 **매일 책을 펼치는 습관**을 우선합니다.

---

## 📁 Structure

```text
reading-log/
├── README.md
│
├── templates/
│   ├── daily.md
│   └── complete.md
│
└── 2026/
    └── books/
        ├── 상식-밖의-경제학/
        │   ├── 2026-10-01.md
        │   ├── 2026-10-02.md
        │   ├── 2026-10-03.md
        │   └── 완독-기록.md
        │
        └── 데이터-문해력/
            └── ...
```

### `templates/`

독서 기록을 작성할 때 사용하는 템플릿입니다.

- `daily.md`: 매일 작성하는 독서 기록
- `complete.md`: 책을 완독한 후 작성하는 기록

### `2026/books/`

연도별로 읽은 책을 관리합니다.

각 책은 하나의 폴더를 가지며,
매일의 기록은 날짜를 파일명으로 사용합니다.

예시:

`상식-밖의-경제학/`

- `2026-10-01.md`
- `2026-10-02.md`
- `2026-10-03.md`
- `완독-기록.md`
